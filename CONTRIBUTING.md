# Contributing

## Prerequisites

| Tool    | Version                                     | Notes                                                                                                 |
| ------- | ------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| Node.js | 24 LTS (`.nvmrc`); ≥ 22.18 is supported     | `nvm use` / `fnm use` picks up `.nvmrc`                                                               |
| pnpm    | pinned in `package.json` (`packageManager`) | Run `corepack enable`. If `corepack` is missing (Node ≥ 25 no longer bundles it): `npm i -g corepack` |
| uv      | latest                                      | Installs the Python version from `.python-version` automatically                                      |
| Docker  | with Compose v2                             | Postgres, full stack, `pnpm lint:ci`                                                                  |

Then: `pnpm bootstrap`.

## Scripts

All tasks are root `package.json` scripts; run them from the repo root.

| Script                                            | What it does                                                                      |
| ------------------------------------------------- | --------------------------------------------------------------------------------- |
| `pnpm bootstrap`                                  | `pnpm install` + `uv sync --all-packages`                                         |
| `pnpm dev`                                        | API, admin and widget dev servers together                                        |
| `pnpm dev:api` / `dev:admin` / `dev:widget`       | One dev server                                                                    |
| `pnpm db:up` / `db:down`                          | Start / stop Postgres in Docker (port 5432)                                       |
| `pnpm db:migrate`                                 | `alembic upgrade head`                                                            |
| `pnpm db:revision "<message>"`                    | New autogenerated Alembic migration                                               |
| `pnpm lint`                                       | ruff + ESLint                                                                     |
| `pnpm lint:ci`                                    | actionlint on the workflows (Docker image, nothing to install)                    |
| `pnpm format` / `format:check`                    | ruff format + Prettier                                                            |
| `pnpm typecheck`                                  | mypy (strict) + `tsc` in every JS package                                         |
| `pnpm test`                                       | All tests; or `test:api`, `test:features`, `test:ml`, `test:widget`, `test:admin` |
| `pnpm build`                                      | api-client generate + type check, `widget.js`, admin bundle                       |
| `pnpm analyze:widget`                             | Build the widget and write a bundle treemap to `apps/widget/dist/stats.html`      |
| `pnpm size:widget`                                | Widget raw/gzip size and budget check (`apps/widget/size-budget.config.mjs`)      |
| `pnpm api:openapi`                                | Export `openapi.json` from FastAPI and regenerate the TS client                   |
| `pnpm api:check`                                  | Fail if the committed `openapi.json` differs from the FastAPI export              |
| `pnpm docker:up` / `docker:down` / `docker:build` | Full stack in Docker                                                              |
| `pnpm docker:config` / `docker:nginx-test`        | Validate the Compose files / the Nginx config                                     |
| `pnpm ml:notebook`                                | JupyterLab in `ml/notebooks`                                                      |
| `pnpm check`                                      | format:check + lint + typecheck + test + api:check — run before every PR          |

Integration tests (`apps/api/tests/integration`) need Postgres (`pnpm db:up`). Without it
they are skipped; with `REQUIRE_DB=1` (set in CI) they fail instead.

## Branches and pull requests

Every change is tied to a Jira issue with the key `CAPTHCA-<n>`.

1. Branch from `main`: `<type>/CAPTHCA-<n>-<short-slug>`, e.g. `feat/CAPTHCA-12-site-settings`.
   Types: `feat`, `fix`, `chore`, `docs`, `refactor`, `test`, `ci`.
2. Small commits with English messages in [Conventional Commits](https://www.conventionalcommits.org/)
   style: `feat(api): add sites repository`.
3. Run `pnpm check`. If you changed the API, run `pnpm api:openapi` and commit
   `packages/api-client/openapi.json`. The TS client in `packages/api-client/src/generated` is
   not committed: it is generated from `openapi.json` on `pnpm install` and before the admin
   build, typecheck and tests.
4. Open a PR titled `CAPTHCA-<n>: <summary>` and fill in the template.
5. CI must be green (`ci-ok`) and at least one review approved before merging. The cubic bot
   also reviews every PR (see the README); treat its comments as suggestions.

Working with an AI coding agent? It follows [AGENTS.md](AGENTS.md); keep that file up to date
when conventions change.

## Settings

Copy `.env.example` to `.env` to override defaults. Never commit `.env`.
